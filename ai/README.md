# ai

This repository contains tools and scripts for AI model evaluation and fine-tuning.

## Submodules

### evaluation
Tools and scripts for evaluating AI model performance, including:
- Metrics calculation
- Performance benchmarking
- Results analysis and visualization

### finetune
Tools and scripts for fine-tuning AI models, including:
- Data preprocessing
- Training pipelines
- Hyperparameter optimization
- Model checkpointing

## Getting Started

1. Clone the repository with submodules: evaluation @ai-tools-evidently finetune @ai-tools-llama-factory
