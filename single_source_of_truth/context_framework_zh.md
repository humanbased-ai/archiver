## 1. 核心身份与使命 (The "Who We Are")

### 1.1. 公司使命 (公开愿景)
打造一个开放、去中心化的多链协议，联合基于区块链的数据基础设施与由人类贡献者及专业AI代理组成的协作网络，将个人知识转化为持久的数字资产和持续的回报。

### 1.2. 一句话电梯演讲
Codatta 是一个 Knowledge-Fi 协议，贡献者通过提供训练AI所需的数据来共同拥有AI的未来。

### 1.3. 核心概念与关键词
- **主要关键词:** 去中心化AI (Decentralized AI), 数据协议 (Data Protocol), 知识金融 (Knowledge-Fi), 贡献即赚取 (Contribute-to-Earn), 数据主权 (Data Sovereignty), 链上数据溯源 (On-chain Data Provenance), AI数据层 (AI Data Layer)。
- **次要关键词:** 大语言模型微调 (LLM Fine-tuning), LoRA, 监督式微调 (SFT), 数据标注 (Data Annotation), 模型即服务 (MaaS), Agent开发者生态 (Agent Developer Ecosystem)。

### 1.4. 目标画像
- **数据贡献者 (The "Crowd"):** 数据科学家、行业专家、学生、知识爱好者。核心动机是赚取收益、获得数据所有权，并为有价值的AI项目做贡献。
- **客户/开发者 (The "Builders"):** AI创业公司、Agent开发者、企业AI实验室。需要高质量、专业化的数据和微调模型。重视速度、可靠性和数据的可追溯性。
- **Web3 参与者 (The "Backers"):** 加密投资者、生态合作伙伴、算力提供商。重视协议增长、通证经济模型和整体Web3愿景。

## 3. 产品与技术深度解析

### 3.1. 核心产品 offerings
- **Codatta 协议:** 基础的、开放的、去中心化的多链协议。
- **Codatta 应用/平台:** 用户与协议交互的前端应用。包含以下模块:
    - 数据贡献与标注 (数据工场)
    - 模型微调 (模型熔炉)
    - 模型评测 (评测竞技场)
    - 模型即服务 (MaaS) API 中心

### 3.2. 用户工作流概览
1.  **数据溯源:** 客户定义数据需求，或贡献者提议一个数据集。
2.  **贡献与标注:** 社区通过 Codatta 应用贡献和标注数据。
3.  **验证与确权:** 数据由同行和AI共同验证；所有权在链上被记录（例如，通过NFT）。
4.  **模型训练:** 客户使用经过验证的数据集来微调AI模型（SFT），生成LoRA适配器。
5.  **价值捕获:** 当数据集或由此产生的模型被商业化使用时，版税通过智能合约自动分配给数据所有者。
