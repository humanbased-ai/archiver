### 1.1. Company Mission (Public Vision)
To build an open, decentralized, multi-chain protocol uniting blockchain-based data infrastructure with a collaborative network of human contributors and specialized AI agents, transforming individual knowledge into lasting digital assets and ongoing rewards.

## 3. Product & Technology Deep Dive

### 3.1. Core Product Offerings
- **Codatta Protocol:** The foundational, open, decentralized multi-chain protocol.
- **Codatta App / Platform:** The user-facing application for interacting with the protocol. Includes modules for:
    - Data Contribution & Annotation (Data Factory)
    - Model Fine-Tuning (Model Foundry)
    - Model Evaluation (Evaluation Arena)
    - Model-as-a-Service (MaaS) API Hub

### 3.2. User Workflow Overview
1.  **Data Sourcing:** A client defines a data need or a contributor proposes a dataset.
2.  **Contribution & Annotation:** The community contributes and labels data via the Codatta App.
3.  **Validation & Ownership:** Data is validated by peers and AI; ownership is recorded on-chain (e.g., as NFTs).
4.  **Model Training:** Clients use the verified datasets to fine-tune AI models (SFT), generating LoRA adapters.
5.  **Value Accrual:** When the dataset or resulting model is used commercially, royalties are automatically distributed to the data owners via smart contracts.
